# Amazon Clone — Full Stack Bootcamp Project

A full-stack e-commerce application inspired by Amazon, built with Next.js and TypeScript as part of my Full Stack Web Development Bootcamp.

This project was developed as a practical learning experience to help students understand how modern, scalable web applications are designed, built, and maintained.

## About the Project

Amazon Clone is an educational full-stack development project created to demonstrate real-world e-commerce application architecture.

Throughout the bootcamp, students learn how frontend interfaces communicate with backend services, how application logic is organized, and how TypeScript improves code reliability and maintainability.

The goal is to move beyond basic tutorials and introduce students to practical software engineering workflows.

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/siliconvalleyman/amazon-clone-course.git
```

Navigate to the project directory:

```bash
cd amazon-clone-course
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

Additional environment variables or services may be required depending on the implementation.
